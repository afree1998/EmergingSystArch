# EmergingSystArch

Summarize the project and what problem it was solving.
This project aimed to create an embedded system that utilized a state machine to monitor room temperature. 

The part that I think I handled well was that I was given a framework to build the system in and by meticulously combing through the various bits that were premade I was able to understand what functions needed to be adjusted and how to go about adjusting them. I created a state machine that worked well, and didn't have any critical errors 

If I were to improve anything it would be the ability to long press the buttons. The state machine monitors for single button presses, and often in a thermostat you will just hold the buttons down instead of pressing them fifteen times. 

I utilize a lot of the materials that exist within this project regularly, but I think the practice of defining the state machine and then implementing it would be something I'm going to add to my work later. It was very interesting, and has a lot of great applications. 

I think the most transferable skill from this project is understanding state machines. I can see many different applications, even outside of embedded systems, where the practice is usable. 

By using comments, I was able to make a maintainable and readable project. By utilizing class structure we were able to make a system that is adaptable.
